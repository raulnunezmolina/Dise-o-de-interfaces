# Tarea 1.6 – Labelling

| Label | Scope note |
|---|---|
| Inicio | Permite acceder a la página principal de la aplicación y consultar los servicios del puerto. |
| Iniciar sesión | Permite acceder a la cuenta introduciendo las credenciales del usuario. |
| Registrarse | Permite crear una cuenta nueva para utilizar los servicios de la plataforma. |
| Mi cuenta | Apartado donde el usuario puede consultar y gestionar su información personal. |
| Mis datos personales | Permite consultar y modificar los datos personales del usuario. |
| Servicios | Muestra todos los servicios disponibles en el puerto. |
| Buscar servicios | Permite encontrar servicios concretos mediante una búsqueda. |
| Filtrar servicios | Permite seleccionar servicios según diferentes criterios. |
| Restaurantes | Muestra los restaurantes disponibles y permite consultar sus servicios. |
| Aparcamientos | Permite consultar las zonas de aparcamiento y su disponibilidad. |
| Amarres | Muestra los amarres disponibles para las embarcaciones. |
| Alquiler de embarcaciones | Permite consultar y alquilar embarcaciones disponibles. |
| Tienda de pesca | Permite consultar los productos de pesca disponibles para comprar o alquilar. |
| Detalles del servicio | Muestra información, características, precios y disponibilidad del servicio seleccionado. |
| Reservar | Permite realizar una reserva de un servicio disponible. |
| Comprar | Permite adquirir productos disponibles en la tienda de pesca. |
| Alquilar | Permite solicitar el alquiler de una embarcación o material disponible. |
| Confirmación y pago | Permite confirmar una reserva o compra y realizar el pago correspondiente. |
| Mis reservas | Muestra las reservas realizadas por el usuario y su estado. |
| Mis compras y alquileres | Permite consultar los productos comprados y los alquileres realizados. |
| Historial | Muestra el registro de las reservas, compras y alquileres anteriores. |
| Cancelar reserva | Permite cancelar una reserva realizada previamente. |
| Información del puerto | Ofrece información general sobre el puerto y sus instalaciones. |
| Sobre el puerto | Muestra información sobre las instalaciones y características del puerto. |
| Servicios y tarifas | Permite consultar los servicios ofrecidos y sus precios. |
| Noticias | Muestra novedades y noticias relacionadas con el puerto. |
| Contacto y ayuda | Ofrece diferentes opciones para resolver dudas y contactar con el puerto. |
| Preguntas frecuentes | Muestra respuestas a las dudas más habituales de los usuarios. |
| Formulario de contacto | Permite enviar consultas o solicitudes de información. |
| Soporte | Permite solicitar ayuda ante problemas relacionados con la aplicación o sus servicios. |
| Panel de cliente | Permite al cliente gestionar su cuenta, reservas, compras y alquileres. |
| Panel de empresa | Permite a las empresas administrar sus servicios y gestionar su actividad en la plataforma. |
| Gestionar servicios | Permite añadir, modificar o eliminar los servicios ofrecidos por la empresa. |
| Gestionar disponibilidad | Permite establecer y modificar la disponibilidad de los servicios. |
| Gestionar reservas | Permite consultar, aceptar, modificar o cancelar las reservas recibidas. |
| Gestionar productos | Permite añadir, modificar o eliminar productos de la tienda de pesca. |
| Gestionar precios y horarios | Permite actualizar las tarifas y los horarios de los servicios. |
| Gestionar empleados | Permite administrar los trabajadores que tienen acceso al panel de la empresa. |
| Panel de empleado | Permite al empleado realizar las tareas diarias relacionadas con su empresa. |
| Consultar reservas | Permite revisar las reservas realizadas por los clientes. |
| Consultar disponibilidad | Permite comprobar los horarios y servicios disponibles. |
| Atender incidencias | Permite gestionar los problemas o consultas comunicados por los clientes. |
| Panel de administrador | Permite supervisar y administrar el funcionamiento general de la plataforma. |
| Gestionar usuarios | Permite consultar, modificar y administrar las cuentas de los usuarios. |
| Gestionar empresas | Permite registrar, consultar y administrar las empresas de la plataforma. |
| Gestionar permisos | Permite asignar y modificar los permisos de acceso de cada tipo de usuario. |
| Supervisar reservas | Permite consultar y controlar las reservas realizadas en los diferentes servicios. |
| Gestionar incidencias | Permite revisar y resolver los problemas comunicados por usuarios y empresas. |
| Consultar estadísticas | Permite visualizar información sobre la actividad y el uso de la plataforma. |
| Cerrar sesión | Permite salir de la cuenta de usuario de forma segura. |
